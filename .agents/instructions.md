# Οδηγίες & Κανόνες Ανάπτυξης AI (AI Reminders) - SpyQBank

*Αυτό το αρχείο διαβάζεται και λαμβάνεται υπόψη από τον AI agent κατά την εκκίνηση του τρέχοντος project για την αποφυγή επαναλαμβανόμενων διευκρινίσεων.*

**Alias χρήστη:** Όταν ο χρήστης αναφέρει `οδηγίες` ή `οδηγιες`, εννοεί αυτό το αρχείο (`instructions.md`), εκτός αν δώσει πιο συγκεκριμένο path.

## ⛔ ΑΠΟΛΥΤΟΙ ΚΑΝΟΝΕΣ ΠΕΡΙΟΡΙΣΜΟΥ (CRITICAL)

1. **ΜΗ ΧΡΗΣΗ ΠΟΡΩΝ:** Αποφεύγουμε εντολές που καταναλώνουν υπερβολική μνήμη ή CPU στο background.
2. **Η Συντόμευση `^` (Hands-off / Shutdown)**:
   - Το σύμβολο `^` ως αυτόνομο μήνυμα χρήστη σημαίνει **hands-off / κλείνουμε για σήμερα**.
   - Μόλις ο χρήστης γράψει `^`, ο AI agent **ΠΡΕΠΕΙ** να τερματίσει/κλείσει αμέσως οποιαδήποτε ενεργή background διεργασία (όπως `uv run flet run`) για να ελευθερωθούν πόροι συστήματος.
   - Ο AI agent ολοκληρώνει τη συνομιλία αποχαιρετώντας ευγενικά τον χρήστη, χωρίς να εκτελέσει νέες ενέργειες, εντολές ή να περιμένει περαιτέρω είσοδο.

## Βασικοί Κανόνες (Σημαντικοί)

1. **Package / Dependency Management:** 
   - Χρησιμοποιούμε **ΠΑΝΤΟΤΕ** `uv`. 
   - Δεν τρέχουμε «γυμνές» pip εντολές. Αξιοποιούμε `uv pip install ...`, `uv add ...` ή `uv run ...`.
   - **CRITICAL:** Εργαλεία που αφορούν μόνο Desktop (π.χ. `pyinstaller`, `watchdog`) πρέπει να μπαίνουν στο `[dependency-groups] dev` και ΠΟΤΕ στα βασικά `dependencies`.

2. **Framework & UI Standards:** 
   - Το project χρησιμοποιεί τη βιβλιοθήκη **Flet** (Material design UI).
   - **Flet Standards**:
     - Χρήση `ft.run(main)`.
     - Χρήση `ft.Button(content=...)`, `ft.TextButton(content=...)` (όχι deprecated `ElevatedButton`, ούτε `text` prop).
     - Χρήση `ft.Border.all()`, `ft.Border.symmetric()`.
     - Χρήση `page.snack_bar` με `page.snack_bar.open = True; page.update()`.
     - Χρήση `ft.Alignment(0, 0)`.
     - Τα custom controls κληρονομούν από `ft.Container` ή παρεμφερή (όχι `UserControl`).
   - **Background Tasks & Live Logging (CRITICAL)**:
     - Κάθε δικτυακή κλήση ή βαριά επεξεργασία (λήψη θεμάτων, downloads PDF, συγχώνευση) εκτελείται μέσω **`page.run_thread(worker)`**.
     - Για logs χρησιμοποιούμε το δοκιμασμένο πρότυπο **`LogConsole`** (ενιαίο `ft.Text` μέσα σε scrollable `ft.Column`) για άμεσο redraw στα Windows.
   - **CRITICAL (Καταγραφή Σφαλμάτων):** Κάθε νέο σφάλμα, ιδιαιτερότητα του Flet API ή Gotcha που επιλύεται κατά την ανάπτυξη, **ΠΡΕΠΕΙ ΥΠΟΧΡΕΩΤΙΚΑ** να καταγράφεται στο αρχείο [`.agents/flet.md`](file:///c:/Users/alekos/pyAlekos/SpyQBank/.agents/flet.md) στην «Ενότητα 3: 🐛 ΕΠΙΛΥΜΕΝΑ ΣΦΑΛΜΑΤΑ & GOTCHAS» για μελλοντική αναφορά.

3. **Pyinstaller & Build (Desktop):** 
   - Δημιουργούμε εκτελέσιμα (.exe) χρησιμοποιώντας: `uv run pyinstaller SpyQBank.spec --clean`. **ΠΑΝΤΑ** προσθέτουμε την παράμετρο `--clean`.
   - **ΠΑΝΤΟΤΕ** διασφαλίζουμε ότι στο spec αρχείο η παράμετρος `console` είναι `False`.

4. **Εκδόσεις (Versioning):** 
   - **CRITICAL:** Όταν αλλάζουμε ακόμη και ένα byte στον κώδικα, δημιουργούμε νέα έκδοση (version bump).
   - Χρησιμοποιούμε **δεκαδικό σύστημα με rollover** (π.χ. μετά το 1.4.9 πάμε στο 1.5.0, ΠΟΤΕ στο 1.4.10).
   - Ενημερώνονται **ΟΛΕΣ** οι αναφορές: `pyproject.toml`, `src/version.py`, `README.md`, και η ενότητα «Τελευταία Γνωστή Κατάσταση» στο `instructions.md`.

5. **Naming Convention (App Name):**
   - Το όνομα της εφαρμογής είναι **`SpyQBank`**.

6. **Ανοχή σε μικρά/κεφαλαία στις οδηγίες χρήστη:**
   - Όταν ο χρήστης αναφέρει αρχείο, εντολή, φάκελο ή σύμβολο με διαφορετικά μικρά/κεφαλαία, ο AI agent πρέπει πρώτα να ψάχνει case-insensitive αντιστοιχίες μέσα στο project.

## 🎯 Προδιαγραφές Έργου SpyQBank (Τράπεζα Θεμάτων ΙΕΠ)

1. **Συγκέντρωση και Ταξινόμηση ανά Κεφάλαιο**:
   - Άντληση δεδομένων από το επίσημο API του ΙΕΠ (`https://api.trapeza.registry.digitalschool.gov.gr/v1`).
   - Δέντρο σχολείων, τάξεων και μαθημάτων (`/public/school/type/tree`).
   - Θέματα ανά μάθημα (`/public/school/type/{typeId}/class/{classId}/subject/{subjectId}/items?up_to_last_chapter=false`).
   - Ομαδοποίηση και κατηγοριοποίηση ανά διδακτική ενότητα / κεφάλαιο (`material`).

2. **Ερώτηση & Απάντηση Μαζί (Pairing - Βασικότερο Όλων)**:
   - Σε κάθε θέμα εμφανίζεται **πάντα** η εκφώνηση και ακριβώς από κάτω η ενδεικτική απάντηση/λύση.
   - Άμεση προβολή ή λήψη των αντίστοιχων PDF (`file_type=1` για εκφώνηση, `file_type=2` για λύση).

3. **Εξαγωγή Αναφοράς σε PDF**:
   - Δυνατότητα παραγωγής ολοκληρωμένου PDF ανά κεφάλαιο ή για όλα τα θέματα ενός μαθήματος.
   - Το παραγόμενο PDF περιέχει σε ζεύγη την εκφώνηση του κάθε θέματος και αμέσως μετά τη λύση του, με όμορφο εξώφυλλο, προσαρμοσμένο τίτλο (πάνω κέντρο), κείμενο υποσέλιδου (κάτω κέντρο), σελιδοποίηση `- χχ -` κάτω δεξιά, ένδειξη `# θέματος` πάνω δεξιά σε κάθε σελίδα, και αυτόματη αποφυγή σφαλμάτων κλειδώματος αρχείων (PermissionError).

4. **Έλεγχος Αλλαγών / Ενημερώσεων (Change Detection)**:
   - Χειροκίνητος ή αυτόματος έλεγχος (polling/sync) για νέα ή τροποποιημένα θέματα στο `trapeza.iep.edu.gr`.
   - Τοπική βάση/cache (JSON/SQLite) για καταγραφή της κατάστασης και επισήμανση των αλλαγών.
