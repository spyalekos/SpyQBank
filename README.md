# 📚 SpyQBank v1.2.9

**SpyQBank** - Εφαρμογή Python & Flet για την οργάνωση, ταξινόμηση και διαχείριση της **Τράπεζας Θεμάτων του ΙΕΠ** (https://trapeza.iep.edu.gr/).

## ✨ Κύρια Χαρακτηριστικά

- 🏫 **Πλήρες Δέντρο Σχολείων & Μαθημάτων**: Επιλογή Τύπου Σχολείου (ΓΕΛ, ΕΠΑΛ), Τάξης και Μαθήματος.
- 📂 **Ταξινόμηση ανά Κεφάλαιο / Διδακτική Ενότητα**: Αυτόματη ομαδοποίηση των θεμάτων ανά κεφάλαιο.
- 💡 **Ζεύγη Θεμάτων & Απαντήσεων (Q&A Pairs)**: Κάτω από κάθε εκφώνηση θέματος εμφανίζεται άμεσα η ενδεικτική απάντηση/λύση.
- 🎨 **Χρωματική Διάκριση & Αφαίρεση Whitespace στο PDF**: Μαύρα γράμματα στις εκφωνήσεις, σκούρα μπλε (#0F2D6B) στις απαντήσεις, και αφαίρεση περιττού λευκού χώρου (white space margins).
- 🔒 **Ασφαλές Κλείδωμα UI (Disable Buttons)**: Κατά τη διάρκεια μαζικών εξαγωγών ή συγχρονισμού, όλα τα κουμπιά απενεργοποιούνται αυτόματα ώστε να αποτρέπονται διπλά πατήματα.
- ⚙️ **Ρυθμίσεις Επικεφαλίδας & Υποσέλιδου (`spyqbank.json`)**: Δυνατότητα ορισμού προσαρμοσμένου τίτλου (πάνω κέντρο) και υποσέλιδου (κάτω κέντρο) που αποθηκεύονται τοπικά στο αρχείο `spyqbank.json`.
- 📑 **Εξαγωγή σε PDF**: Παραγωγή ενιαίου PDF ανά κεφάλαιο ή για όλο το μάθημα, με διαδοχική τοποθέτηση θέματος και λύσης, κεντρικό τίτλο και υποσέλιδο, επικεφαλίδα # θέματος πάνω δεξιά, αρίθμηση σελίδων κάτω δεξιά (`- χχ -`), και αυτόματη αποφυγή σφαλμάτων κλειδώματος αρχείων.
- 🔄 **Έλεγχος Αλλαγών**: Χειροκίνητος ή αυτόματος έλεγχος για νέα ή τροποποιημένα θέματα στο ΙΕΠ.
- ⚡ **Offline Cache**: Τοπική αποθήκευση μεταδεδομένων και αρχείων για άμεση πρόσβαση.

## 🚀 Εγκατάσταση & Εκτέλεση

```bash
uv sync
uv run flet run src/main.py
```
